WEBSITE PORTOFOLIO - AYAM GEPREK JUARA

Cara menjalankan:
1. Buka index.html di browser.
2. Semua desain ada di style.css.
3. Interaksi/animasi ada di script.js.
4. Ganti nomor WhatsApp pada index.html jika diperlukan.
5. Ganti nama, alamat, harga, dan foto sesuai pelanggan.

Catatan:
- Ini adalah demo portofolio.
- Foto menggunakan URL Unsplash sehingga membutuhkan internet.
- Domain dan hosting tidak termasuk.
